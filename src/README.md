# Código-fonte da aplicação

Este diretório contém uma página estática mínima apenas como **exemplo da estrutura inicial exigida na Sprint 1**.

Execute com:

```bash
python -m http.server 8000 --directory src
```

Depois acesse `http://localhost:8000`.

O grupo deve substituir essa estrutura pelo projeto real e documentar:

- tecnologias e versões;
- pré-requisitos;
- instalação das dependências;
- configuração de variáveis de ambiente;
- criação/migração do banco de dados;
- execução do frontend e backend;
- credenciais de demonstração sem expor senhas reais;
- comandos de testes.

> Não versionar `.env`, tokens, senhas ou chaves. Forneça apenas `.env.example` quando necessário.
