# Slides da apresentação final

Coloque nesta pasta os slides efetivamente utilizados no vídeo.

Recomendado:

- arquivo editável (`.pptx`, `.odp` ou equivalente), quando possível;
- versão em PDF para facilitar a visualização;
- imagens, fontes ou recursos necessários à apresentação, respeitando licenças.

Atualize `docs/entrega-final.md` com o nome e o link dos arquivos.
