# Registros de reuniões

Registre decisões e encaminhamentos relevantes das reuniões do grupo. Fotografias ou capturas podem ser incluídas como evidência complementar, mas **não substituem** o registro textual.

Use nomes como:

```text
2026-08-18-planejamento-sprint-01.md
2026-09-10-revisao-requisitos.md
```

Cada registro deve conter:

- data e participantes;
- objetivo;
- decisões tomadas;
- tarefas, responsáveis e prazos;
- impedimentos;
- links para Issues ou documentos afetados.

Consulte [`modelo-ata.md`](modelo-ata.md).
